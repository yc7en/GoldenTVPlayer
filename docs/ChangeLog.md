# ChangeLog（对外发布版）

> 面向用户的变更日志，随版本发布对外提供，版本号与发布版本一致。
> 标题 = 日期 + 版本号，版本号与发布版本一致（语义化版本）。
> 前缀：`新增` / `修改` / `修复` / `架构`，按用户可感知变更归纳。

---

## 2026-10-30 (v1.1.0)

- 新增：搜索页「历史」标题行最右侧新增清空按钮，点击后二次确认，确定即清空全部搜索记录（电视端与手机端行为一致）。清空只影响搜索关键词，播放历史与收藏不受影响。

## 2026-10-29 (v1.0.0)

首个对外发布版本。基线 v5.8.3 之上进行了安全加固、瘦身、品牌改造与播放栈重构，含多处破坏性变更（移除功能、行为收紧）。

- 新增：m3u8 插播广告过滤，入口为播放设置开关，静默过滤不打扰观看。
- 新增：手机端详情页「全屏播放」按钮，全屏态与画中画中自动隐藏。
- 新增：手机端设置页及子设置页顶部返回按钮。
- 新增：TLS 证书校验默认严格，设置页可显式开启「允许不安全证书」（默认关，需二次确认）。
- 新增：崩溃详情一键复制（含版本 / 设备 / 堆栈 / 操作轨迹）。
- 新增：音频增强新增「音轨偏移」（软件 DSP，±10s）。

- 修改：应用名与图标改为「金幕影音 / GoldenTVPlayer」。
- 修改：自更新默认关闭，仅构建时注入仓库才启用。
- 修改：运行时插件目录默认空，需构建时注入目录。
- 修改：本地服务默认仅监听本机，局域网访问需 6 位配对码。
- 修改：播放栈改用官方 media3，渲染输出固定 SurfaceView，移除解码模式对话框。

- 修复：Android 14+ 启动即崩（DLNA 服务缺 WAKE_LOCK 权限）。
- 修复：平板横屏布局缺控件导致的播放页崩溃。
- 修复：进度条拖拽松手不跳转的问题。
- 修复：局域网模式下误拦本机回环请求的问题。

- 架构：移除磁力 / BT / ed2k 播放（thunder 模块）。
- 架构：移除 mpv 第二引擎，主 APK 单引擎化。
- 架构：禁用脚本源（type=3 Spider），配置加载阶段丢弃。
- 架构：本地服务鉴权模型收紧（契约 C-5）。

## 版本号提升规则

- `MAJOR`：不兼容的破坏性变更
- `MINOR`：向后兼容的新功能
- `PATCH`：向后兼容的缺陷修复
