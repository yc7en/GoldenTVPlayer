# Features · 功能清单

> **一句话描述每个功能**，是"当前代码实际行为"的事实记录，不写实现细节、不写设计意图。
> 状态：✅ 已实现 ｜ 🚧 开发中 ｜ 📋 规划中 ｜ 🗑 废弃
>
> **ID 规则**：`F-<域><序号>`，一经分配**永久不变、不复用**。功能废弃时把状态改 🗑 并保留行。
> 本文件为对外发布版，仅保留功能现状，不含内部开发流水。
